Pertemuan 3 PBKK C: Membuat Scientific Calculator

Mata kuliah: Pemrograman Berbasis Kerangka Kerja C (2026)
Pertemuan: 3 — Calculator Apps

Pada latihan ini saya membuat aplikasi kalkulator ilmiah desktop menggunakan C# dan Windows Forms pada .NET untuk Windows. Aplikasi menyediakan tombol interaktif, tampilan ekspresi dan hasil, serta mesin evaluasi ekspresi matematika.

Catatan cakupan: Dashboard kelas menandai Pertemuan 3 sebagai “Calculator Apps”. Rincian di bawah merupakan rekonstruksi berdasarkan dokumentasi tugas PBKK C yang terhubung di laporan, bukan salinan instruksi resmi dosen. Implementasi ini menyusun ulang fitur inti sebagai project mandiri.

Fitur

  • Operasi tambah, kurang, kali, bagi, tanda kurung, pangkat, persen, dan faktorial.
  • Fungsi sin, cos, tan, asin, acos, atan, akar kuadrat dan akar kubik.
  • Logaritma natural (ln), logaritma basis 10, nilai absolut, exp, dan 10 pangkat x.
  • Konstanta π dan e serta tombol Ans untuk hasil sebelumnya.
  • Mode derajat (DEG) dan radian (RAD).
  • Memori kalkulator: MC, MR, M+, M−, MS.
  • Tombol hapus karakter, reset, pembulatan, dan pintasan keyboard.
  • Validasi ekspresi, pembagian nol, domain fungsi, serta hasil yang tidak valid.

Rancangan program

Program.cs menginisialisasi Windows Forms dan membuka form kalkulator. CalculatorForm.cs membangun antarmuka dan menangani tombol. CalculatorEngine.cs mengevaluasi ekspresi dengan recursive descent parser berlapis sesuai prioritas operasi: penjumlahan, perkalian, pangkat, unary, dan postfix faktorial. Evaluasi dilakukan langsung oleh parser sendiri tanpa mengeksekusi teks sebagai kode.

Penggunaan

Tekan tombol untuk menyusun ekspresi lalu tekan =. Tombol DEG/RAD mengganti satuan sudut. Fungsi seperti sqrt(25), sin(30), dan 2^3 dapat dimasukkan melalui keypad.

Menjalankan aplikasi

Project ini membutuhkan Windows dan .NET 10 SDK dengan workload Windows Forms.

dotnet run --project "Pertemuan 3/PBKKC.Pertemuan3.csproj"

Kesimpulan

Project ini menerapkan pemrograman event-driven pada Windows Forms, pemisahan UI dan logika perhitungan, validasi input, serta parsing ekspresi matematika dengan operator precedence.
