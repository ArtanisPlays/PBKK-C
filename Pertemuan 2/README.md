# PBKK C — Pertemuan 2

Dua implementasi untuk cakupan yang terlihat pada laporan PBKK C 2026:

- Console: Hello World dan sistem data mahasiswa CRUD — jalankan `dotnet run --project PBKKC.Pertemuan2.csproj`.
- Windows Forms: aplikasi desktop data mahasiswa dengan tambah, edit, hapus, cari, tabel, dan ringkasan IPK — jalankan `dotnet run --project DesktopStudentManager/DesktopStudentManager.csproj`.
