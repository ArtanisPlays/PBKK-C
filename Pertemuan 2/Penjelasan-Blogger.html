Pertemuan 2 PBKK C: Pengenalan .NET dan Sistem Data Mahasiswa

Mata kuliah: Pemrograman Berbasis Kerangka Kerja C (2026)
Pertemuan: 2

Pada latihan ini saya mempelajari cara membuat aplikasi console menggunakan C# dan .NET. Program pertama menampilkan teks sederhana, kemudian dikembangkan menjadi sistem data mahasiswa yang berjalan di terminal.

Catatan: Deskripsi tugas ini direkonstruksi dari topik dan laporan mahasiswa PBKK C pada pertemuan 2. Silakan sesuaikan bila dosen memberikan instruksi atau format pengumpulan yang lebih spesifik.

Tujuan

  • Mengenal struktur project .NET dan entry point Main.
  • Menggunakan class dan object untuk memodelkan data mahasiswa.
  • Mengelola koleksi data dengan List<Student>.
  • Membuat operasi tambah, tampil, cari, ubah, dan hapus (CRUD).
  • Memvalidasi input menggunakan TryParse dan menampilkan data dalam tabel console.

Fitur aplikasi

  1. Menambahkan mahasiswa dengan NIM, nama, program studi, dan IPK.
  2. Menolak NIM duplikat serta input wajib yang kosong.
  3. Menampilkan semua data dalam tabel berkolom rapi.
  4. Mencari data berdasarkan NIM, nama, atau program studi.
  5. Mengedit nama, program studi, dan IPK tanpa mengubah NIM.
  6. Menghapus data setelah konfirmasi pengguna.
  7. Memastikan IPK berupa angka dalam rentang 0 sampai 4.

Struktur dan alur program

Class Student menyimpan identitas dan informasi mahasiswa. Class Program menyimpan daftar mahasiswa selama aplikasi berjalan dan menampilkan menu berulang. Setiap pilihan menu memanggil method terpisah agar fungsi program mudah dibaca dan dikembangkan.

Data disimpan sementara di dalam List<Student>. Karena belum memakai database atau file, data akan hilang ketika program ditutup.

Validasi input

Program memeriksa kolom wajib, memastikan NIM tidak duplikat, dan mem-parsing IPK dengan double.TryParse. Tanda koma desimal juga diterima. Nilai yang tidak valid ditolak sehingga aplikasi tidak berhenti akibat kesalahan input.

Cara menjalankan

dotnet run --project "Pertemuan 2/PBKKC.Pertemuan2.csproj"

Source code: Program.cs dan PBKKC.Pertemuan2.csproj pada folder project.

Versi desktop Windows Forms

Folder DesktopStudentManager berisi alternatif antarmuka desktop yang juga muncul pada dokumentasi PBKK C. Aplikasi menampilkan tabel data, formulir tambah dan edit, pencarian langsung, penghapusan dengan konfirmasi, jumlah mahasiswa, serta rata-rata IPK. NIM menjadi identitas tetap saat data diedit. Data versi desktop juga disimpan sementara di memori.

Untuk menjalankannya di Windows dengan .NET 10 SDK:

dotnet run --project "Pertemuan 2/DesktopStudentManager/DesktopStudentManager.csproj"

Kesimpulan

Latihan ini menerapkan dasar C#/.NET, class, object, koleksi dinamis, percabangan, perulangan, pencarian, validasi, dan operasi CRUD dalam aplikasi console.
